# 🏋️ FitPilot AI

FitPilot AI is a modern Gym Management System that helps gym owners manage members, attendance, workouts, and daily operations from a single dashboard.

## ✨ Features

- 👤 Member Management
- 📅 Attendance Tracking
- 🔐 Secure Authentication
- 📊 Dashboard & Analytics
- 💪 Workout Management
- 🤖 AI-Powered Features
- ☁️ Supabase Backend
- 📱 Responsive Design

## 🛠 Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase
- PostgreSQL
- Node.js

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Technoanshu/FitPilot-AI.git
```

Go to project folder

```bash
cd FitPilot-AI
```

Install dependencies

```bash
pnpm install
```

Run the development server

```bash
pnpm dev
```
